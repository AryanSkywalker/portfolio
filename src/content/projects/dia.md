I had the idea of this project in my mind but couldn't really fathom how it can be implemented into code
much as less work for any realtime usecase. The variety in answer sheets was just too much and so I designed my
very own answer sheet sample that was curated to work for my pipeline and after weeks of brainstorming, the project
came along fine!

It employs rudimentary image manipulation to get a binary scan of the sheet after which we define regions and extract
our answers. The entire process is on display in my github repository if you wanna check it out.
